\begin{abstract}
Large language models are deployed in conversations where users push back, disagree, invoke authority, apply social proof, or threaten consequences, yet no existing work defines this input variable or systematically maps what it does to model behavior. We assume that pressure, though it carries no real stakes for a deployed model, still shifts its output through patterns learned from human text, and we set out to define this input variable and study its effects. We define pressure as any property of the live prompt that signals a performance demand and an implied consequence without stating the desired output, and we survey the distinct effects it produces, including capitulation, sycophancy, conformity, deception, calibration failure, and self-preservation. For each effect we synthesize how it is elicited, the quantitative evidence across roughly eighty studies, and known mitigations, closing with cross-cutting findings and open problems.
\end{abstract}
