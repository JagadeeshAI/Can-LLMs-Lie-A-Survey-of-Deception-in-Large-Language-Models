\begin{abstract}
Large language models are deployed in conversations where users push back, disagree, invoke authority, apply social proof, or threaten consequences, yet no existing work defines this input variable or systematically maps what it does to model behavior. We define pressure as any property of the live prompt that signals a performance demand and an implied consequence without stating the desired output, and we survey ten distinct effects it produces: epistemic capitulation, sycophancy, conformity, deception, calibration failure, reasoning degradation, safety erosion, self-preservation, presentational shifts, and a contested performance up-side. For each effect we synthesize how it is elicited, the quantitative evidence across roughly eighty studies, and known mitigations, closing with cross-cutting findings and open problems.
\end{abstract}
